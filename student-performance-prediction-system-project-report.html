⚙️ ML Pipeline

Preprocessing (src/preprocess.py)

  • LabelEncoder applied to all 13 categorical columns — encoders saved as encoders.pkl
  • StandardScaler applied to all 6 numerical columns — scaler saved as scaler.pkl
  • 80 / 20 train-test split (stratified random, seed 42)

🚀 How to Run

Double-click run_app.bat or run from terminal:

python -m streamlit run app.py --server.port 8501

Then open http://localhost:8501 in your browser.

To retrain models (if data changes):

python src/train.py
